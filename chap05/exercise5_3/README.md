# Exercise 5.3
This problem uses the PairOfDice class from 
<a href="https://github.com/ken-wakura-pro/Java-Revision-Exercises/tree/master/chap05/chap05_exercises/exercise_5_1">Exercise 5.1</a> 
and the StatCalc class from <a href="https://github.com/ken-wakura-pro/Java-Revision-Exercises/tree/master/chap05/chap05_exercises/exercise5_2">Exercise 5.2</a>.

The program in <a href="https://github.com/ken-wakura-pro/Java-Revision-Exercises/blob/master/chap04/chap04_exercises/RollDice10k.java">Exercise 4.4</a>
performs the experiment of counting how many times a pair of dice is rolled
before a given total comes up. It repeats this experiment 10000 times and then
reports the average number of rolls. It does this whole process for each
possible total (2, 3, ..., 12).

Redo that exercise. But instead of just reporting the average number of rolls,
you should also report the standard deviation and the maximum number of rolls.
Use a PairOfDice object to represent the dice. Use a StatCalc object to compute
the statistics. (You'll need a new StatCalc object for each possible
total, 2, 3, ..., 12. You can use a new pair of dice if you want, but it's not
required.)
